# 作業チケット（Notion）

チケットは Notion の「チケット管理」DB（プロジェクトページ: https://app.notion.com/p/6a5187beecfc833d88ac81f0da29801f ）。ID は `ACG-n`。進め方の正はそのページの「チケットドリブンの進め方」。ここには Agent がよく使う部分だけを書く。

## ステータス

| 段階 | 付けるステータス |
|---|---|
| 着手 | `AI:設計・計画中` → `AI:実装中` → `AI:検証中`（分けないなら `AI:進行中`） |
| 人の判断が要る | `人間:判断待ち` + `## 判断待ち: <一言>` 節（聞きたいこと・選択肢・推奨） |
| 他の作業待ち | `保留` + `## 保留: <一言>` 節（待っているもの・再開の条件） |
| やりきった | `人間:解決済 (確認中)` + `## 成果` 節（やったこと・PR・確かめ方） |

- `人間:進行中`・`クローズ`・`中止`・`featured` は人が付ける。AI は触らない（「質問:」チケットのクローズだけは AI 可）
- AI の作業中は Next 列に `~HH:MM 終了見込み`（JST）と、要れば `・補足` の 2 行目を書く。作業中でなくなったら空にする

## 本文

- 実装 / 調査 / chore は「実装内容概要 → 背景情報のトグル → Pull request」の形。判断待ち・保留・成果・次の一手 の節はその後ろに足す
- `## Pull request` に PR の URL を書く
- 関連チケットは背景情報にページのメンションで貼る（双方向）
- 進捗はチケット数ではなくテストケースの通過数で測る。実装チケットには対応するケース ID を書く

## スレッド名

`[フェーズ][種類][ACG-n] 日本語の要約`。フェーズは P0準備 / P1検証設計 / P2最小実装 / P3品質向上。
