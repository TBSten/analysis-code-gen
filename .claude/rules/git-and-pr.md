# コミットと PR

## branch とマージ

- `main` から branch を切り、PR を `main` へ出す。main への直接 push はしない
- CI が緑なら Agent が自分で **squash マージ**してよい（てべすてん、2026-11-25）
- CI を通すためにテストを skip・削除・緩めない（R-01）。落ちたら原因を直す
- 他人（他スレッド）の branch の履歴は書き換えない

## コミット

- 1 コミット 1 意図、小さく。メッセージは日本語で `<種類>: <要約> [ACG-n]`
  - 種類: `feat` / `fix` / `test` / `docs` / `chore` / `refactor` / `port`（上流からの移植）
  - 例: `test: GRD-01〜05 の保留テストを追加 [ACG-44]`
- 生成物・ビルド結果・秘密情報はコミットしない

## PR

- タイトルは `[ACG-n] 日本語の要約`
- 本文は `.github/PULL_REQUEST_TEMPLATE.md` の見出しを埋める: チケット / 変更内容 / ケース ID / ADR / テスト（保留の増減）/ 確認したこと
- 保留を外したケース、追加した保留ケースを ID で列挙する。有効なテストを止めた変更は出さない
- マージしたら Notion チケットの `## Pull request` と `## 成果` を更新する
